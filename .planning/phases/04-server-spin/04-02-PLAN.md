**조회 타입의 진실(RESEARCH §Q-2, `deno check` 타입 폭로 실측):**
- `.from("candidates").select("restaurant_id, created_at, restaurants ( id, name )")` 의 추론 타입은 `{ restaurant_id: any; created_at: any; restaurants: { id: any; name: any }[] }[] | null` — **임베드가 배열이라고 주장한다.** PostgREST 런타임은 many-to-one 을 **객체**로 준다. `row.restaurants[0].name` 은 컴파일 통과 + 런타임 `undefined`, `row.restaurants.name` 은 정답인데 컴파일 에러. ⚠ 이 페이즈 최대 함정
- `.from("settings").select("spin_time, cooldown_days").eq("id", 1).maybeSingle()` → `{ spin_time: any; cooldown_days: any } | null`. 0행은 `data: null, error: null`
